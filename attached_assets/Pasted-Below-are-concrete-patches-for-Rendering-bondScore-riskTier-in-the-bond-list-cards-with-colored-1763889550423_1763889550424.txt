1️⃣ Backend: PATCH /api/bonds/:id/score

File: server/routes.ts

a) Make sure you have zod imported

At the top (if it’s not there already):

import { z } from "zod";

b) Add the new route under BOND ROUTES

Place this near your other bond routes, but before the admin routes:

  // Update only the AI-derived bond score + risk tier
  app.patch(
    "/api/bonds/:id/score",
    authMiddleware,
    async (req: AuthRequest, res) => {
      try {
        const bondId = Number(req.params.id);
        if (!Number.isFinite(bondId)) {
          return res.status(400).json({ error: "Invalid bond id" });
        }

        const bond = await storage.getBond(bondId);
        if (!bond) {
          return res.status(404).json({ error: "Bond not found" });
        }

        // Ownership / admin check
        if (bond.ownerId !== req.user!.id && req.user!.role !== "admin") {
          return res.status(403).json({ error: "Forbidden" });
        }

        const ScoreSchema = z.object({
          bondScore: z.number().int().min(0).max(100),
          // optional riskTier override, otherwise we'll derive it
          riskTier: z.enum(["low", "moderate", "high"]).optional(),
        });

        const parsed = ScoreSchema.safeParse(req.body);
        if (!parsed.success) {
          return res.status(400).json({
            error: "Invalid score payload",
            details: parsed.error.flatten(),
          });
        }

        const { bondScore, riskTier } = parsed.data;

        // Keep a single canonical mapping for risk tier
        const derivedTier: "low" | "moderate" | "high" =
          riskTier ??
          (bondScore >= 70
            ? "low"
            : bondScore < 40
            ? "high"
            : "moderate");

        const updated = await storage.updateBond(bondId, {
          bondScore,
          riskTier: derivedTier,
        });

        return res.json(updated);
      } catch (error) {
        console.error("Update bond score error:", error);
        return res
          .status(500)
          .json({ error: "Failed to update bond score" });
      }
    }
  );


Now you can:

PATCH /api/bonds/123/score
Authorization: Bearer <token>
Content-Type: application/json

{
  "bondScore": 82
}


…and the backend will:

Confirm ownership/admin.

Clamp & validate score 0–100.

Derive riskTier based on your mapping.

Persist both fields in the bonds table.

b) Add helpers for styling

Inside the file, near the top (but below imports), add:

function getRiskTierClasses(
  tier: Bond["riskTier"]
): string {
  if (!tier) return "bg-slate-100 text-slate-800";

  switch (tier) {
    case "low":
      return "bg-emerald-100 text-emerald-800";
    case "moderate":
      return "bg-amber-100 text-amber-800";
    case "high":
      return "bg-red-100 text-red-800";
    default:
      return "bg-slate-100 text-slate-800";
  }
}

function formatBondScore(score: number | null): string {
  if (score == null) return "Not scored";
  return `${score}/100`;
}

3️⃣ (Optional) Frontend hook to re-score using the new endpoint

If you want a quick UI action to re-score a bond (e.g., later when you add a “Re-run AI scoring” button), you can add something like this inside BondsPage:

async function updateBondScore(bondId: number, score: number) {
  const res = await fetch(`/api/bonds/${bondId}/score`, {
    method: "PATCH",
    headers: {
      "Content-Type": "application/json",
      ...authHeaders(),
    },
    body: JSON.stringify({ bondScore: score }),
  });

  if (!res.ok) {
    const text = await res.text();
    throw new Error(text || "Failed to update bond score");
  }

  const updated = (await res.json()) as Bond;

  // update local list
  setBonds((prev) =>
    prev?.map((b) => (b.id === bondId ? updated : b)) ?? prev
  );
}


Then later you can tie that to:

A “Re-score” button that runs AI on the server and calls this.

Or a manual override input in an admin-only UI.
