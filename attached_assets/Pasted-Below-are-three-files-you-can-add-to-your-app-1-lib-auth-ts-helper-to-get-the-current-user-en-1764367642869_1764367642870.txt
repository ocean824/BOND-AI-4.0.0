You can tweak imports (@/lib/...) to match your project, but the structure is ready to paste.

1) lib/auth.ts – auth + ADMIN-only helper
Adapt this to your real auth (NextAuth, JWT, custom, etc.). The important part is that it returns a user with a role field and rejects non-admins.

/**
 * Ensure the request comes from an ADMIN.
 * Throws a Response (NextResponse.json) if not.
 */
export async function requireAdminUser(req: NextRequest): Promise<AuthUser> {
  const user = await getAuthUser(req);

  if (!user) {
    throw new Response(
      JSON.stringify({ error: "Unauthorized" }),
      { status: 401, headers: { "Content-Type": "application/json" } },
    );
  }

  if (user.role !== "ADMIN") {
    throw new Response(
      JSON.stringify({ error: "Admin access required" }),
      { status: 403, headers: { "Content-Type": "application/json" } },
    );
  }

  return user;
}

3) Next.js API route – /app/api/admin/bonds/[bondId]/generate-docs/route.ts
This is the route you asked for. It:
•	Accepts POST only.
•	Checks that the caller is ADMIN using requireAdminUser.
•	Reads { step, suretyCaseId, trustId } from the JSON body.
•	Calls generateDocsForBondStep(...).
•	Returns the generated docs as JSON.
// app/api/admin/bonds/[bondId]/generate-docs/route.ts
import { NextRequest, NextResponse } from "next/server";
import { requireAdminUser } from "@/lib/auth";
import {
  generateDocsForBondStep,
  type BondProcessStep,
} from "@/lib/documentEngine";

// Optional: tighten allowed steps at runtime:
const ALLOWED_STEPS: BondProcessStep[] = [
  "JUDGMENT_TO_BOND",
  "PERFECTION",
  "SURETY_UNDERWRITING",
  "SURETY_ACTIVATION",
  "EXCHANGE_LISTING",
  "EXCHANGE_SALE",
  "TRUST_ALLOCATION",
];

export async function POST(
  req: NextRequest,
  context: { params: { bondId: string } },
) {
  try:
    // 🔐 Admin-only: throws Response if not authorized
    await requireAdminUser(req);

    const bondId = context.params.bondId;
    const body = await req.json();

    const { step, suretyCaseId, trustId } = body as {
      step: BondProcessStep | string;
      suretyCaseId?: string;
      trustId?: string;
    };

    if (!bondId) {
      return NextResponse.json(
        { error: "Missing bondId in route params" },
        { status: 400 },
      );
    }

    if (!step || !ALLOWED_STEPS.includes(step as BondProcessStep)) {
      return NextResponse.json(
        {
          error:
            "Invalid or missing step. Must be one of: " +
            ALLOWED_STEPS.join(", "),
        },
        { status: 400 },
      );
    }

    const docs = await generateDocsForBondStep({
      bondId,
      step: step as BondProcessStep,
      suretyCaseId,
      trustId,
    });

    return NextResponse.json({ docs }, { status: 200 });
  } catch (err: any) {
    // If requireAdminUser threw a Response, just re-throw it
    if (err instanceof Response) {
      throw err;
    }

    console.error("Doc generation error:", err);
    return NextResponse.json(
      { error: "Failed to generate documents" },
      { status: 500 },
    );
  }
}
Investor lockout:
Even if an INVESTOR hits this URL:
•	requireAdminUser will reject them (401/403).
So they get zero access to doc generation for any step of the pipeline.

4) How to call this from your Admin UI
On the admin side (e.g. in a React component on your dashboard):
// example in an Admin React component
async function generateDocs(
  bondId: string,
  step: BondProcessStep,
  options?: { suretyCaseId?: string; trustId?: string },
) {
  const res = await fetch(
    `/api/admin/bonds/${bondId}/generate-docs`,
    {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        step,
        suretyCaseId: options?.suretyCaseId,
        trustId: options?.trustId,
      }),
    },
  );

  if (!res.ok) {
    const data = await res.json().catch(() => ({}));
    throw new Error(data.error ?? "Doc generation failed");
  }

  const data = await res.json();
  return data.docs as {
    id: string;
    docType: string;
    storagePath: string;
  }[];
}
Then your admin UI can have buttons like:
•	“Generate Bond Docs” → generateDocs(bondId, "JUDGMENT_TO_BOND")
•	“Generate Surety Package” → generateDocs(bondId, "SURETY_ACTIVATION", { suretyCaseId, trustId })
•	etc.
