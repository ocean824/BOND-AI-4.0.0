In Replit, open the relevant page(s), likely something like:

app/src/pages/BondsPage.tsx

or a section of JudgmentsPage.tsx / BondIntakePage.tsx where you create new records.

You want this pattern:

Only plain inputs for real fields: CUSIP, coupon, maturity, face value, etc.

No buttons that auto-fill or generate fake/example data.

Search in the file for any of these patterns and remove them:

mock

sample

demo

fillWithSample

Buttons with labels like “Use example bond”, “Load demo bond”, etc.

If you currently have something like:
