# BONDS Feature Pack

This zip contains **all new code and patch notes** for the `BONDS` feature:

- AI‑assisted bond document drafting & editing (OpenAI)
- Bond document upload (PDF / DOCX) + AI summarization & tagging
- Frontend `BondsPage` for creating and managing real bond instruments
- Patch notes for wiring schema, storage, routes, and nav in your existing BondAI app

You can drop these files into your repo and apply the patch notes in `docs/BONDS_PATCH_NOTES.md`.
